# Release Notes: Next Update

这份文案用于下一次 Chrome Web Store 更新说明。包含一版中文和一版英文，可按后台长度要求截取。

## 中文短版

本次更新把扩展从“微信读书专用提醒”升级为“微信读书阅读页默认支持 + 普通网页按站点启用”的护眼提醒工具。新增 `20-20-20` 模式、休息引导、最近 `7 / 30` 天健康报告、中文 PDF 导出、原始数据 CSV 导出，以及更清晰的健康说明和数据管理界面。所有统计和报告仍然只保存在本地浏览器中。

## 中文长版

本次更新包含：

- 微信读书阅读页默认支持，普通网页可按站点单独启用
- 新增 `20-20-20` 模式，提醒时带 `20 秒` 倒计时
- 新增休息引导步骤，支持 reduced-motion 退化
- 新增最近 `7 / 30` 天用眼健康报告
- 支持导出中文 PDF 报告
- 支持导出原始数据 CSV，便于备份和自行分析
- Options 页面重新整理了信息层级
- 新增健康说明与更明确的本地隐私提示

说明：

- 微信读书阅读页仍然默认支持
- 对其他普通 `http/https` 网站，仍然只会在你主动授权当前站点后启用
- 当前 `专业版预览` 只是本地功能预览，不是正式订阅系统
- 所有数据依旧只保存在浏览器本地，不会上传到远端服务器

## 英文 Short

This update turns the extension from a WeRead-only reminder into a broader eye-care tool: WeRead reader pages work by default, and other sites can be enabled one by one. It adds a built-in 20-20-20 mode, guided break steps, local 7/30-day reports, Chinese PDF export, raw CSV export, and clearer health/privacy messaging. All stats and reports remain local-only.

## 英文 Long

What’s new in this update:

- WeRead reader pages work by default, with site-by-site enablement for other pages
- A built-in 20-20-20 mode with a 20-second break countdown
- Guided break steps with reduced-motion fallback
- Local 7-day and 30-day eye-care reports
- Chinese PDF report export
- Raw CSV export for backup and self-analysis
- A cleaner Options page hierarchy
- Clearer health notice and local-privacy messaging

Notes:

- WeRead reader pages remain supported by default
- Other normal `http/https` sites still require explicit per-site permission
- The current Pro preview is a local feature preview, not a live billing system
- All data remains stored locally in the browser
